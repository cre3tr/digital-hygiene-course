# Lesson 2: Passwords

You can't remember a different strong password for every account, and nobody expects you to. That's what a password manager is for.

**Use the password manager your business gives you.** It creates and remembers a different strong password for every account, and fills it in for you. If your business doesn't have one yet, ask. Cartman Systems can set one up for the team.

**One password, one account.** When a site you use is breached, the attackers try that email and password everywhere else. If every password is different, one breach stays one breach.

**Don't share logins.** If two people need the same account, each gets their own login, or the account is shared through the password manager. Then a login can be removed when someone leaves, without changing it for everyone.

## Do this now

- I use the business's password manager for work accounts.
- No two of my work accounts share a password.
- I don't share my logins. Shared accounts go through the password manager.

## Quick check

A website you signed up to years ago says it was breached. Your work email uses the same password. What's the risk?

- A) None. It was a different website.
- B) Attackers will try that password on your work email next.
- C) Only that old website is affected.

<details><summary>Show answer</summary>

**B.** Breached passwords are tried automatically on other sites. Change the work password today, and use a unique one from now on.

</details>
